# 第3回 解答

## 演習

- 第1回（素のLLM）とエージェントの回答の違い：エージェントは用語集を検索してから答えるため、LoRA と QLoRA の定義に基づいた回答になり、最後に「第2回」と示した。
- `--trace` で見えたツール呼び出し（ツール名と引数）：変更前は `search_glossary({'query': 'LoRA'})` と `search_glossary({'query': 'QLoRA'})`、変更後は `search_glossary({'query': 'LoRA QLoRA'})`。
- 1つの質問での LLM 呼び出し回数（`requests`）：変更前 2 回、変更後 2 回（ツール呼び出しは 2 回から 1 回）。
- 追加したツールと、docstring に書いた説明：`make_quiz(lecture)`。指定した回の確認問題を作るときに使い、用語集から用語を1つ選んで問題と定義を返す。該当する用語がない場合はメッセージを返す。

## 宿題

- 取り組んだレベル：基礎
- やったこと：`search_glossary` の docstring を「用語を1つだけ入れる」から「用語をまとめて入れる」に変更し、同じ質問を `--trace` 付きで実行した。
- 結果：変更前は LoRA と QLoRA を別々に検索したが、変更後は `LoRA QLoRA` を1回で検索した。回答内容は両者の違いを説明する形で、関係する回も維持された。
- 気づき・疑問：ツールの docstring もモデルへの指示になるため、コードを変えなくてもツールの呼ばれ方が変わる。`uv run pytest -q` は15件成功した。
